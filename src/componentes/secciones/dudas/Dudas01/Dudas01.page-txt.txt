DUDAS01 — GUÍA PARA page.tsx
=============================

QUÉ ES
------
Componente de preguntas y respuestas tipo acordeón.

Diseñado mobile-first y adaptado a los patrones visuales de Alred.

No utiliza:
- eyebrow "Preguntas frecuentes";
- badges;
- iconos decorativos;
- cambio de tipografía;
- símbolos + y −.

Utiliza una única flecha por pregunta.


RUTA
----
src/componentes/secciones/dudas/Dudas01/


USO
---

<Dudas01

AÑADIR PREGUNTAS
----------------
No tienes que modificar el componente.

Solo añade otro objeto dentro del array:

{
  pregunta: "Nueva pregunta",
  respuesta: "Nueva respuesta",
}

Puedes tener 5, 6, 10 o las que necesites.


ABRIR OTRA PREGUNTA POR DEFECTO
--------------------------------

Primera:

abiertaInicial={0}

Segunda:

abiertaInicial={1}

Todas cerradas:

abiertaInicial={null}


COMPORTAMIENTO
--------------
- Solo hay una pregunta abierta cada vez.
- Pulsar la abierta la cierra.
- Pulsar otra abre la nueva.
- Animación de altura suave sin calcular píxeles.
- Funciona con touch real.
- Funciona con teclado.
- Respeta prefers-reduced-motion.
- La flecha gira para indicar apertura.


RESPONSIVE
----------
El CSS está escrito mobile-first.

Móvil:
- una columna;
- objetivo táctil amplio;
- pregunta y respuesta con padding compacto;
- flecha única.

Tablet/desktop:
- encabezado a dos columnas;
- marco más ancho;
- mayor respiración interna.


EXPORT
------

src/componentes/secciones/dudas/index.ts

con:

Y en:

src/componentes/secciones/index.ts

añadir:
