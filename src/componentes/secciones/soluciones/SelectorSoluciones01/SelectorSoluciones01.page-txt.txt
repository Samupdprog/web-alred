USO EN UNA PÁGINA [slug]
------------------------
Por ejemplo, en automatizaciones:

<SelectorSoluciones01
  activa="automatizaciones"

  soluciones={...}
/>

El componente mueve automáticamente la solución activa a la primera posición
y le aplica un borde ligeramente distinto.

No muestra badges ni texto "Activo".


ARQUITECTURA
------------
El componente NO conoce las rutas de la aplicación.

Cada item recibe:

href

Esto permite reutilizar el mismo componente con cualquier locale o estructura
de navegación.


PROPS
-----
SelectorSoluciones01Props:

id?: string

titulo?: string

descripcion?: string

soluciones: SolucionSelectorItem[]

activa?: string


SolucionSelectorItem:

slug: string
titulo: string
descripcion: string
href: string

imagen: string
imagenAlt?: string

imagenX?: number
imagenY?: number

imagenXMobile?: number
imagenYMobile?: number


IMÁGENES
--------
Las imágenes son abstractas/decorativas.

Por eso pueden dejar:

imagenAlt: ""

para evitar ruido en lectores de pantalla.


RESPONSIVE
----------
Móvil:
- 1 columna

Tablet:
- 2 columnas

Desktop:
- se usan tantas columnas como soluciones haya, hasta un máximo de 5

Esto permite usar ahora 4 soluciones y añadir posteriormente
"Herramientas internas" sin rehacer el componente.


INTERACCIÓN
-----------
Toda la tarjeta es un enlace.

No se anidan links dentro de la tarjeta.

En desktop:
- elevación muy ligera
- zoom de imagen sutil
- desplazamiento de flecha

En touch no se aplican efectos hover.


SEO / SEMÁNTICA
---------------
- sección con h2
- cada solución usa h3
- enlaces rastreables hacia cada /soluciones/[slug]
- aria-current="page" en la solución activa


EXPORT GENERAL
