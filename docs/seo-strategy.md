# SEO Strategy

SEO for Alred should be useful, technical and natural. The goal is qualified discovery, not keyword stuffing.

## Principles

- One clear search intent per page.
- Unique title and description per public route.
- Canonical and alternate language URLs.
- Natural service copy with real business context.
- Schema.org when it describes true business information.
- Internal links between related services and contact paths.

## Technical Foundation

- Metadata is handled with the Next.js Metadata API.
- `src/app/sitemap.ts` generates the sitemap.
- `src/app/robots.ts` generates robots rules.
- Bilingual routes use `/es` and `/en`.
